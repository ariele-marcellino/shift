# SHIFT — Roblox store page

Copy the text inside a block into the experience's **Description** field (Creator Hub → your
experience → Basic Settings). Roblox shows plain text only — no Markdown — so the blocks below are
written to look right as plain text. Limit: 1000 characters.

## Title

```
SHIFT — 3v3 Capture the Flag
```

## Description (English)

```
SHIFT — 3v3 Capture the Flag in a facility that fights back.

Steal the enemy flag and run it home — but every capture SHIFTS the facility: security doors slam shut, the power cuts out, tunnels open and close. The map you learned a minute ago is gone.

• AK or bolt-action sniper, karambit knife, frag & smoke grenades
• Shoot out the lights to fight in the dark, shatter windows and climb through
• Bots fill empty slots — jump in anytime, solo or with friends
• First team to 3 captures wins

Tip: the flag carrier only has a knife, so escort them!
```
